Аналитика платформы

Быстрые выборки по обучению и активности

Здесь собраны быстрые запросы для операционной аналитики: состав участников, наполнение курсов, активность по событиям и статистика зачислений. Это помогает быстро проверять состояние платформы.

Пользователи по домену

Быстро показывает, из каких организаций приходят участники.

Здесь появится список пользователей с выбранным доменом почты.

Курсы с преподавателем

Удобно для проверки учебной нагрузки и закрепления программ.

Результат покажет курсы и преподавателей, которые их ведут.

Контент по курсу

Проверка наполнения выбранной программы по урокам и модулям.

Здесь появится последовательность материалов выбранного курса.

Статистика записей

Позволяет быстро оценить спрос на курсы и текущую загрузку.

Здесь будет статистика количества студентов по курсам.

События по диапазону дат

Подходит для просмотра активности платформы за конкретный период.

Результат отобразит события, попадающие в выбранный диапазон дат.

Участники события

Показывает аудиторию выбранного вебинара, встречи или интенсива.

Здесь будет список участников выбранного события с email.
